# Roteirista de Bolso

Web app pessoal (PWA) pra iPhone e Mac: grava uma ideia de vídeo em áudio e acompanha o robô que transforma
a ideia em roteiro de YouTube.

- Este repositório tem **só o código do app**. Nenhum dado pessoal fica aqui.
- O app manda o áudio pra um repositório **privado** do dono; lá um GitHub Actions transcreve, busca os vídeos
  mais vistos dos últimos meses sobre o tema, lê os 2 primeiros minutos de cada, escreve o roteiro e entrega
  no Google Doc e no Trello.
- A chave de acesso do GitHub fica só no aparelho.

Publicação: GitHub Pages, branch `main`, pasta raiz. No iPhone: Safari › Compartilhar › Adicionar à Tela de Início.
